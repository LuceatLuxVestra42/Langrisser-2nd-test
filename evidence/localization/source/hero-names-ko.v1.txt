# - Hero canonical identity, canonical population, public admission, release 상태, Hero 간 또는 다른 객체와의 relation authority가 아니다.
# - current Hero identity/population/relation의 최종 기준은 repository가 지정한 current authoritative source와 owning validator를 따른다.
# - 이 파일의 이름은 HeroID를 대체하지 않으며, 이름 일치만으로 새로운 identity, JOIN, relation, population을 만들지 않는다.

# - 동일명, 변형명, 중복 후보, 표기 충돌이 생기면 filename similarity, 순서, ID arithmetic 등으로 자동 해소하지 않고 MANUAL_REVIEW 또는 owning localization source 확인으로 넘긴다.
# - 신규 영웅이나 이 파일에 없는 이름을 임의 번역하여 검수 완료 이름으로 추가하지 않는다.
# - current project localization source 또는 한섭 공식 표시와 authoritative contradiction이 확인되면 해당 localization owner에서 재검토한다.
# - 개별 이름의 외부 provenance는 이 파일에 기록되어 있지 않으므로, 공식성·release 시점·출처 증명이 필요한 작업에서 이 파일 단독으로 provenance를 확정하지 않는다.
