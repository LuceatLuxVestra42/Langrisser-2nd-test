# 랑그릿사 출전작 / 진영 한글화 작업용 — localization / presentation reference
# 역할 경계 보강: 2026-09-12
#
# [문서 역할과 authority 경계]
# - 이 파일은 Hero presentation에서 사용하는 출전작/진영 분류의 ID, 중국 표시명, 한국 표시명을 정리한 localization 작업용 reference다.
# - Hero canonical population, 출전작/진영 canonical population, Hero↔출전작·Hero↔진영 semantic relation의 authority가 아니다.
# - current identity/population/relation의 최종 기준은 repository가 지정한 current authoritative source와 owning validator를 따른다.
# - 이 파일의 이름, ID 배열, 표시 순서만으로 새로운 identity나 relation을 만들지 않는다.
# - production/frontend에서 별도 frozen/generated metadata 또는 localization consumer가 존재하면 current consumer와 owning contract를 우선한다.
#
# [presentation eligibility 경계]
# - `LLR 영웅은 한글화 대상 분류 산출에서 제외` 규칙은 이 작업 파일의 localization/presentation 대상 범위를 뜻한다.
# - 위 제외 규칙을 canonical Hero 삭제, canonical relation 제거, 출전작/진영 population 변경으로 해석하지 않는다.
# - 화면 노출/필터 대상과 canonical population/relation은 별도로 검증한다.
#
# [한국명 사용 규칙]
# - 기존 한국명은 localization 표시/reference로 사용한다.
# - `[한글화 필요]`는 미확정 표시 상태이며 임의 번역으로 confirmed 이름에 승격하지 않는다.
# - 이름 일치만으로 Hero나 다른 객체와 JOIN하지 않는다.
# - 이름 충돌, 변형명, 신규 ID, 관계 불일치는 name JOIN, ID arithmetic, 순서 기반 추론으로 해결하지 않고 MANUAL_REVIEW 또는 owning localization/semantic source를 확인한다.
#
# [count와 snapshot 경계]
# - 이 파일 하단의 출전작/진영 개수는 이 파일에 기록된 당시 localization 작업 대상의 count다.
# - 해당 count를 current canonical population, current release 상태, current admission의 authority로 사용하지 않는다.
# - 신규 항목 여부와 현재 대상 범위는 current repository authority와 presentation/localization owner를 다시 확인한다.
#
# [non-scope]
# - Hero canonical identity/population 판정
# - Hero↔출전작 / Hero↔진영 relation 생성·재계산
# - release/admission 상태 판정
# - LLR 또는 기타 객체의 canonical 제외
# - 이름 유사성 기반 자동 JOIN
